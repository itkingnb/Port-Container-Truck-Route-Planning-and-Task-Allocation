# 自动化港口水平运输仿真系统 (Port Logistics Simulation)

## 🚀 项目进展 (Current Progress)
本项目旨在构建一个高度仿真的自动化港口物流调度系统，通过多智能体协同实现集装箱的高效运输。

### 核心功能
* **环境建模**：实现了随机港口布局生成，包含堆场、岸吊区及行车道。
* **智能体系统**：完成卡车类（Truck）构建，支持动态生成与状态管理。
* **任务系统**：支持随机物流任务生成与实时下发。
* **路径规划**：采用 **A* 算法** 实现最短路径搜索，并集成基础避让逻辑。

## 🛠 待开发模块 (To-Do List)

### 1. 运筹优化：多车任务分配 (Assignment Optimization)
* **算法**：匈牙利算法 (Hungarian Algorithm)
* **目标**：解决“多对多”最优匹配。
* **逻辑**：通过代价矩阵 $M_{i,j}$（车 $i$ 与任务 $j$ 的距离/耗时），计算全局最优解，使多台空闲卡车领取的总路程最短。

### 2. 机器学习：智能预测模块 (Machine Learning Integration)
*方案 3 选 1：计划采用方案 A 以增强调度的前瞻性。*

* **方案 A：任务价值预测（回归分析）**
    * **描述**：训练模型预测任务的“潜在延误代价”。
    * **公式**：$Score = \frac{ML\_Predicted\_Urgency}{Distance}$
* **方案 B：动态路径代价预测（时间序列）**
    * **描述**：使用 LSTM 预测未来 30s 的路口拥堵概率，动态调整 A* 权重实现提前绕行。
* **方案 C：深度强化学习 (DRL)**
    * **描述**：使用 PPO/DQN 算法，让智能体在环境中自主学习最优驾驶策略。

## 🔬 算法逻辑说明
* **寻路**：基于网格地图的 A* 启发式搜索。
* **避让**：基于传感器半径的检测，当检测到邻近车辆时执行等待或重新规划代价（Re-routing）。
