Implementation Summary
New files (6)
File	Purpose
task_value_predictor.py	ML task value prediction — random forest ensemble replacing static distance cost with urgency+distance+waiting composite score
congestion_predictor.py	Congestion heatmap with EWMA trend prediction, hotspot detection, persistence to JSON
reinforcement_agent.py	Q-Learning agents + MultiAgentCoordinator for autonomous decision-making and conflict resolution
web_server.py	Flask REST API (/api/state, /api/step, /api/reset, /api/auto, /api/config)
templates/index.html	Web dashboard with metric cards, task/truck lists, control panel
static/dashboard.js	Canvas-based port renderer with pan/zoom, congestion heatmap, real-time updates
Modified files (5)
File	Key changes
tasks.py	Added urgency, deadline, priority_score, waiting_since fields; compute_priority() method; history tracking
truck.py	Added RL state dict, trajectory deque, utilization tracking, to_dict() serialization
path_planning.py	Integrated CongestionPredictor into A* edge costs; instant + trend penalties; visited set optimization
simulation.py	Integrated all 3 modules; replaced distance-only cost with ML scoring; auto task generation; metrics collection; step_once()/reset()/get_state_dict() for web mode
main.py	CLI args (--mode web/matplotlib, --trucks, --cols, --rows, --no-ml, --no-congestion)
How to run

# Matplotlib mode (original, with new features)
python main.py --trucks 6 --cols 12 --rows 5

# Web mode (new)
python main.py --mode web --trucks 6 --cols 12 --rows 5
# Then open http://127.0.0.1:5000

# Disable ML (fall back to distance-only cost)
python main.py --mode web --no-ml --no-congestion
Test results
